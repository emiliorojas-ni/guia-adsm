# Guía interactiva ADSM — Unidad I

Guía de estudio con 182 diapositivas, diagramas SVG animados y 910 ejercicios de completar.

- [Abrir la guía interactiva](https://emiliorojas-ni.github.io/guia-adsm/)
- [Descargar los diagramas en ZIP](https://emiliorojas-ni.github.io/guia-adsm/Diagramas_ADSM.zip)

La guía está contenida en `index.html` y también puede descargarse y abrirse en un navegador. El archivo ZIP reúne los diagramas para su descarga.

Publicado con GitHub Pages desde la raíz de la rama `main`.
